# skills

A collection of custom Claude Code skills.

## Installation

```bash
npx skills add estines/skills          # all skills
npx skills add estines/skills/<name>   # single skill
```

## Skills

| Skill | Trigger | Purpose |
|-------|---------|---------|
| [squad](squad/SKILL.md) | `/squad` | A small software-dev-business squad (PO, BA, Architect, Principal reviewer, platform Seniors, QA, DevOps) that runs a project end-to-end through phase gates. Greenfield, Brownfield (reverse-engineer/audit), and Feature modes — each starts with an Execution Preview you approve before anything runs. |
